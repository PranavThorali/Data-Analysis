# 🏠 House Market Analysis Dashboard

## 📌 Project Overview
This project analyzes the **housing market** using **SQL Server** for data preparation and **Power BI** for visualization.  
The goal is to uncover insights about housing prices, trends, and property value factors, while presenting them through an interactive dashboard.

## 🛠 Tools & Technologies
- **SQL Server** – Data storage, cleaning, and transformation  
- **Power BI** – Dashboard creation and data visualization  
- **DAX (Data Analysis Expressions)** – Calculations and measures  

## 📊 Dashboard Features
- Price distribution by region, property type, and year  
- Interactive slicers and filters  
- Trend analysis of housing prices over time  
- KPIs: average price, total listings, growth rate  

## 📂 Files in Repository
- `HouseMarket.pbix` → Power BI dashboard  
- `README.md` → Project documentation  

## 🚀 How to Use
1. Clone this repository.  
2. Open the `HouseMarket.pbix` file in **Power BI Desktop**.  
3. Update SQL Server connection if needed.  
4. Explore the dashboard interactively.
